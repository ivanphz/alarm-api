# 00-README — 从这里开始

> alarm-api：一个 Cloudflare Worker 网关，按日历和日型算出「什么时候把手机调成什么状态」，
> 由 iPhone 快捷指令执行。
>
> **最后一次全量梳理：2026-07-31**（规则原子化完成，服务端就绪待部署）

---

## 1. 五分钟看懂这个项目

```
日历(ICS) ─┐
法定节假日 ─┼→ [规则] → 时间线（几点该做什么） → 手机快捷指令执行
起床闹钟  ─┘                    ↑
                          你在 config.user.js 里调
```

- **服务端只做决策**，不执行；手机端只执行，不判断
- 每个「几点做什么」叫一个**边界**
- 边界的时刻可以是固定的（07:44），也可以是**算出来的**（出差日跟着闹钟走）
- 手机在固定时刻被**时间自动化**（刺客）叫醒；算出来的时刻靠**门铃**（Bark 推送）叫醒

## 3.5 ⛔ 十一条不变量（违反即架构损伤）

改任何东西之前先扫一眼这张表。**它们和「政策」不同 —— 政策随时可改，
这些改了别处会静默塌掉**（判据见 [09-KERNEL](09-KERNEL.md) §17.5）。

| # | 不变量 | 违反的后果 |
|---|---|---|
| 1 | **信封形状冻结** —— 键集 / 缺席vs null / 零裸布尔 / `alarms.sweep` 授权位 | 打断已装配的手机端 |
| 2 | **插件纯函数** —— `produce()` 禁读时钟、禁 I/O | golden 失效、`?date=` 预览崩 |
| 3 | **消费者只认规则名** —— 不碰生产者内部，不看别的字段的值 | 删一个模块炸另一个，回到耦合地狱 |
| 4 | **token 唯一权威** —— 显示名永不参与比较、不入 `la` | 换语言全字段重放；比较随 iOS 版本漂移 |
| 5 | **单一 owner** —— 每张 schedule 一个 owner，区间不重叠 | 产出打架且无法归因 |
| 6 | **回传是事实非实况** —— 云端 diff 永远 advisory，本地是最终裁判 | KV 最终一致 → 控制回路震荡 |
| 7 | **Gate 标签冻结** —— 只许新增 `GateDyn-<新族>-`；构造唯一入口 `domain/alarm-labels.js` | 动一字 = 全设备手工重录闹钟 |
| 8 | **网关零 iPhone 概念** —— 服务端禁用「列表/urgent/归档/提醒事项」等词 | 契约被平台细节污染，换平台重写 |
| 9 | **验收三条** —— 测试全绿 + 新逻辑有反例用例 + `src/kernel/` diff 为零 | 碰 kernel = 选错了层 |
| 10 | **大版本迁移必做能力对等清点** | v1→v2 真丢过两处功能（[13-HISTORY](13-HISTORY.md) §3.4） |
| 11 | **跨平台契约零平台字符串** —— 包名/本地名只存在于 `resolve` 表 | 上安卓时全部返工 |

## 4. 三条纪律（踩过坑才写下来的）

### 4.1 手机能力的问题，查 05-FACTS，不查外部文档

2026-07-31 犯过：用网络搜索的结论覆盖了两周前的实机实测，结论正好相反
（搜索说"iOS 没有通知触发自动化"，实际有且早就在用）。

> **台账里没有的才去实测；实测完写回台账。外部资料只能当线索，不能当结论。**

### 4.2 加边界前先想它落不落在刺客上

落不上就需要门铃；门铃没开 = 那一刻**永远送不出去**，而且不报错。
`/v2/schema` 的 `automations` 段和 trace 里的 `needs_doorbell` 会告诉你。

### 4.3 ⭐ 改完代码就改文档，别攒着

这个项目的文档烂过一次：加了日型轴、改了时刻、改了形状，而 `PHONE.md` 还写着旧时刻、
`RULEBOOK.md` 还在讲已退役的机制。**烂掉不是因为写得差，是因为没人在改代码时顺手改。**

所以有了下面这张表 —— 改了左边，就必须改右边：

| 改了什么 | 必须同步 |
|---|---|
| 规则时刻 / 日型条件 / 形状判据 | 02-RULES §时刻表；若刺客变了还要改 04-PHONE §自动化清单 |
| 信封字段（增删改） | 03-CONTRACT；手机端读取逻辑 |
| 手机端指令步骤 | 04-PHONE |
| 任何实机测试结论 | 05-FACTS（**当场写，别等**） |
| 部署方式 / 环境变量 | 06-OPERATIONS |
| 做完一个阶段 | 07-ROADMAP 划掉；结论上提到 01/02；**过程直接删**（git 里有），教训进 08 |
| 踩了坑 / 推翻了某个判断 | 08-LESSONS（防重犯） |
| 做了个重要取舍 | 13-HISTORY §3（防误拆 —— 将来有人想简化时能看到理由） |
| 契约条目增删 | 09-KERNEL，并 `grep -rn "契约" src/` 确认没有断链 |

**自查**: 提交前问一句「这次改动让哪个文档说了假话？」——有就一起改。
